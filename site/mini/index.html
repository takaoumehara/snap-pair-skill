Shake Pairing Mini Apps

Three browser-only prototypes demonstrating shake-based device pairing. Shake your phone to find a partner, or use a room code to join manually. Everything runs in your browser - no server-side state.

How It Works

  • Shake Pairing: On iOS Safari, tap "enable shake" (required for DeviceMotionEvent permission). Shake your device. When two devices shake within ~1.5 seconds for the same app, they're automatically paired into a room.
  • Matchmaking Lobby: Shake events are sent to a PartyKit shake lobby. The lobby pairs two shakes for the same app and returns a 6-character room code to both devices.
  • Room Transport: Once paired, devices join a BroadcastChannel room (same-origin local pairing) or can use the room code to join manually from other browsers/devices.
  • Fallback: Every page shows a room code input and QR code so you can join without shaking. Add ?debug=1 to enable a "simulate shake" button for desktop testing.

Technical Details

  • Shake Detection: Monitors accelerationIncludingGravity for magnitude peaks above a threshold (~15g). Detects ~3 peaks within 1 second as a shake gesture.
  • iPhone Safari: Requires DeviceMotionEvent.requestPermission() from a user tap. The permission UI is built into each app.
  • No Unsupported APIs: Uses only standard Web APIs. WebRTC with STUN for P2P, relay fallback via PartyKit if DataChannel fails.
  • Monochrome Style: Follows the creativity-is-everywhere design system with a mobile-first, monochrome palette.
